# 문항 및 시험 규칙 검토 기록

## 현재 문제은행: 1,000문항

2026-11-08(KST), 사용자의 1,000문항 확충 요청에 따라 **기존 60문항을 그대로 보존하고 940개를 추가**했다.
기본 JSON 실제 1,000개 모두 자체 제작·내부 검토 완료. 원문 기출 0, 복원 0, 자체 제작 1,000.
계산 조건 변형 960개 = 기존 6유형 × 10조건 + 추가 30유형 × 30조건. 별도 개념형 40개. 목표 대비 부족 0개.
검증 대기·오류·ID 및 본문/보기 중복 등록 0개. 개인 로컬 등록분은 포함하지 않는다.
과목은 기존 잠정 학습 분류 `열설비 설치·운전 및 관리` 1,000개이며 공식 영역별 배분을 뜻하지 않는다.
**독립 개념 1,000개나 기출 1,000개가 아니다.** 계산 family는 수식/질문 템플릿별 묶음이며 서로 완전히 독립된 출제 단원 36개를 뜻하지 않는다.
예를 들어 현열/배기가스 열회수는 같은 에너지 보존의 적용, 탄소/수소/메탄 연소는 화학량론의 적용이다.

## 실제 근거와 이용 조건

AI의 일반 지식으로 자체 작성했다. 읽지 않은 교재나 공식 자료를 인용하지 않는다.
sourceUrl은 이 작성·검토 기록의 위치이며 외부 정답 증빙이 아니다. 외부 자료를 신규 취득하거나 공식 내용을 재확인하지 않았다.
직접 작성한 문제·해설은 CC BY 4.0(프로젝트명/저장소 출처 및 변경 표시).
전기기능사 문제나 민간 기출을 복사하지 않았다. 출제 연도·회차는 전부 null이다.
기출 원문의 재배포 이용 조건은 확보하지 못했으므로 기출을 등록하지 않았다.

## 검수 범위와 한계

- 계산 템플릿 36개와 개념 원고 40개를 내부 문장 검토했다. 조건 부족·단위·정답의 유일성·오답 해석을 점검했다. 법령의 미확인 수치·특정 제조사 운전값을 만들지 않았다.
- 계산은 조건 → 공식 → 단위 환산 → 대입 → 결과를 해설에 기록한다. 가정(정상상태, 단열, 상변화 유무, 이상기체, 절대압, 효율/발열량 기준)을 문제에 명시했다. 물성값은 문제에 주어진 가정값이며 실제 증기표 인용으로 표시하지 않았다.
- Python 생성 코드와 별도로 TypeScript에서 보존식/상태식을 입력변수에 대해 역으로 풀었다. 정밀 계산값과 반올림된 보기 구간이 모두 원래 입력값과 일치하는지 960개 각각 검사한다. 단위, 수치상 다른 보기 4개, 정답 번호, 반올림 후 정답 유일성, 해설의 최종 결과를 확인한다.
- 개념형은 보일러 구조·열회수·배관·수처리·연소·계측·기본 안전 원칙을 작성했다. 구체 작업은 설비·현장 절차를 따르도록 설명했다. 개념 자동 검사는 원고 정답의 선택지 재배치 보존을 확인하며 개념의 진위를 자동 입증하는 검사가 아니다.
- ID 및 NFKC/공백 정규화 본문·보기 집합으로 중복 검사한다. 보기 재배치 중복도 가져오기 테스트로 확인한다. 의미상 같은 계산 템플릿의 숫자 변형은 family로 공개한다. 조건이 다른 수치 변형을 독립 개념으로 세지 않는다.
- 기존 60개 전 필드/ID 보존은 직렬화 SHA256 회귀 검사로 확인한다. 저장 namespace와 기존 학습 기록 형식은 바꾸지 않았다.
- 해설 문장 내부 검토·계산 검증·외부 전문가 검수·공식 출제기준 대조는 서로 다르다. **외부 전문가 검수 및 공식 출제기준 전체 대조 미완료**. 이 문제은행은 계산 비중이 높고 공식 시험의 과목별/난이도 분포를 보장하지 않는다.
- `scripts/concepts.json`은 개념 원고, `scripts/expanded_bank.py`는 추가 계산 템플릿/조건, `scripts/generate-bank.py`는 전체 재생성 진입점이다. 무작위 생성 없이 ID/순서/조건이 고정되며 반복 생성의 바이트 동일성을 확인했다.

## 공식 시험 규칙 확인 상태

Q-Net 공식 페이지 후보 https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7761 요청은 CONNECT 403으로 실패했다(HTTP 응답 000). 종목 코드 및 페이지 내용도 검증되지 않았다.
공식 시험 과목·출제기준·시간·채점·합격·과락을 이번 작업에서 공식 확인 완료했다고 주장하지 않는다.
앱 `src/qualification.ts`는 에너지관리 학습을 위한 잠정 설정: 열설비 설치·운전 및 관리, 60문항·60분·4지선다·100점 환산·60점 이상 합격·과락 없음·미응답 오답.
이는 전기기능사 공식 규칙의 전용으로 보증하는 값이 아니다. 공식 자료 확보 후 설정과 테스트 대조가 필요하다.
영역별 고정 출제 수는 보증하지 않는다. 시험 추출은 family별 한 문항과 개념형 개별 문항을 각 1개 슬롯으로 묶어 무작위로 60개를 선택한다. 현재 36개 계산 family와 40개 개념 문항으로 76개 슬롯이 있으므로 기본 은행에서는 숫자 변형 family가 같은 시험에 반복되지 않는다. 사용자 수입 은행이 60개 슬롯보다 적으면 고유 ID로 보충하는 기존 정책을 유지한다.

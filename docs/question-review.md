2026-11-08(KST). 기본 JSON 실제 60개, 모두 자체 제작·내부 검토 완료.
원문 기출 0, 복원 0, 자체 제작 60. 숫자 조건 변형 60개 = 6개 유형 × 10개 조건.
독립 개념 1,000개가 아니며 목표 1,000개 대비 부족 940개. 검증 대기/중복 제외분은 0개.
과목은 잠정 학습 분류 `열설비 설치·운전 및 관리` 60개이며 공식 영역별 배분을 뜻하지 않는다.

## 실제 근거와 이용 조건

AI의 일반 지식으로 열량·효율·연료 발열량·압력·체적 유량·열출력을 작성했다.
읽지 않은 교재나 공식 자료를 근거로 인용하지 않는다. sourceUrl은 작성·검토 기록의 위치이며 외부 정답 증빙이 아니다.
직접 작성한 문제·해설과 양식은 CC BY 4.0(프로젝트명/저장소 출처 및 변경 표시).
전기기능사 문제와 민간 기출을 복사하지 않았다. 연도·회차는 모두 null.
외부 기출 원문의 재배포 이용 조건은 확보하지 못했으며 기출을 등록하지 않았다.

## 검수 범위

- 각 유형의 가정과 차원 검토: 일정 비열·상변화 없음, 유효 열량/투입 열량 구별, 저위발열량 기준, 수직 균일 하중, 일정 유량, 일정 열출력.
- 조건 → 공식 → 단위 → 대입 → 결과를 각 해설에 기록했다. 압력에는 kN/m² = kPa, 열출력에는 kW = kJ/s를 명시했다.
- 별도 TypeScript 역산 테스트로 입력 복원, 정답 번호, 4개의 수치상 다른 보기, 소수 둘째 자리 결과를 확인한다. Python 생성식을 테스트로 복사하지 않았다.
- ID 및 NFKC/공백 정규화 본문·보기 집합으로 중복 확인. 보기 순서가 바뀐 수입 중복도 테스트한다.
- 의미상 검토 결과 같은 family의 10개는 숫자 변형이다. family가 다른 6개는 서로 다른 물리량/목표식을 묻는다. 개념 다양성 부족은 공개하며 독립 유형으로 60개라고 주장하지 않는다.
- 해설 문장 내부 검토와 계산 검증은 외부 전문가 검수·공식 출제기준 대조가 아니다. 외부 전문가 검수 미완료. 법령 수치 문항은 넣지 않았다.
- 재생성은 `python scripts/generate-bank.py`. 무작위 생성 없음, ID/순서/입력이 고정된다. 실제 60문항은 시험 범위 전체를 대표하지 않으며 개념·안전·설치·운전 문제 확충이 필요하다.

## 공식 시험 규칙 확인 상태

Q-Net 공식 페이지 후보 https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7761 요청은 CONNECT 403으로 실패했다(HTTP 응답 000). 종목 코드 및 페이지 내용도 검증되지 않았다.
공식 시험 과목·출제기준·시간·채점·합격·과락을 이번 작업에서 공식 확인 완료했다고 주장하지 않는다.
앱 `src/qualification.ts`는 에너지관리 학습을 위한 잠정 설정: 열설비 설치·운전 및 관리, 60문항·60분·4지선다·100점 환산·60점 이상 합격·과락 없음·미응답 오답.
이는 전기기능사 공식 규칙의 전용으로 보증하는 값이 아니다. 공식 자료 확보 후 설정과 테스트 대조가 필요하다.
영역별 고정 출제 수는 보증하지 않는다. 시험 추출은 family 우선 선택 후 부족 슬롯에 고유 ID를 채운다. 현재 한 회 60문항이므로 6개 family가 각 10번씩 출제된다.
